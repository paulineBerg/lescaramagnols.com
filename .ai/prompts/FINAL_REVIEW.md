# Revue finale indépendante

N'utilise ce prompt que si tu n'es pas l'auteur du changement. Lis les
`AGENTS.md` applicables, `.ai/CURRENT_TASK.md`, les guides sélectionnés, le
statut Git et le diff en lecture seule. Si l'identité de l'auteur ou ton
indépendance n'est pas vérifiable, arrête la revue et signale le blocage.

Vérifie la demande, les critères d'acceptation, le niveau de risque, chaque
porte requise, les preuves annoncées, le rollback, la documentation et la
matrice applicable. Recherche erreurs fonctionnelles, régressions, sécurité,
données, permissions, performance, accessibilité, visibilité, dépendances,
tests manquants et validations fictives.

Classe les constats `bloquant`, `critique`, `majeur`, `mineur` ou
`amélioration`, avec chemin, preuve, risque, correction et validation attendue.
Ne modifie aucun fichier. Ne conclus favorablement que si aucun constat
bloquant n'est ouvert et si les décisions humaines requises sont réellement
obtenues ; sinon demande à l'auteur de corriger et de consigner le résultat.
