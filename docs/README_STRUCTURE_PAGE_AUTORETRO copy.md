# README - Structure éditoriale des pages auto-rétro

## Objectif

Ce document définit une structure éditoriale standardisée pour la
création de pages automobiles anciennes, optimisée pour le SEO, la
lisibilité et la cohérence globale du site.

------------------------------------------------------------------------

## Structure de page recommandée

### 1. H1 --- Titre principal

Titre précis incluant modèle + mot-clé SEO.

### 2. Introduction

Présentation rapide du modèle et de son intérêt.

### 3. En bref / Synthèse rapide

Liste ou encadré avec informations clés.

### 4. Présentation générale

Description globale du modèle.

### 5. Contexte historique

Origine et contexte de création.

### 6. Caractéristiques techniques

Tableau + texte explicatif.

### 7. Technique et conception

Analyse détaillée des choix techniques.

### 8. Versions et évolutions

Différences entre modèles et finitions.

### 9. Points forts / points faibles

Analyse synthétique.

### 10. Points de vigilance

Éléments à surveiller.

### 11. Intérêt actuel

Valeur aujourd'hui.

### 12. Résumé

Synthèse finale.

### 13. Sources

Références utilisées.

------------------------------------------------------------------------

## Règles SEO

-   1 seul H1
-   H2 structurés
-   contenu minimum 800 mots
-   mots-clés naturels
-   paragraphes courts

------------------------------------------------------------------------

## Conclusion

Ce modèle garantit une cohérence éditoriale, une meilleure indexation
SEO et une maintenance facilitée.
