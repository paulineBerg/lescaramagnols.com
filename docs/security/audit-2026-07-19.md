### 2. Audit dépendances frontend (`npm audit`)

Commande : `npm audit` (frontend, 2026-07-19).
Résultat : **11 vulnérabilités** (1 low, 3 moderate, 5 high, 2 critical).

**Classification : exposition production nulle.** Le `package.json` frontend ne déclare
aucune dépendance runtime (`dependencies` absent) ; tous les paquets touchés sont des
`devDependencies` (chaîne de build/test Vite). Le site publié est un build statique :
ces vulnérabilités n'affectent que le poste de développement (serveur de dev Vite,
runner de tests), pas la production.

### 3. Headers de sécurité production

Commande : `composer check-security-headers -- --url=https://www.lescaramagnols.com` (GET HTTP depuis le poste local).
Résultat : statut final 200, **tous les headers requis présents** (CSP, X-Frame-Options,
X-Content-Type-Options, Referrer-Policy, Permissions-Policy, COOP, CORP).

### 4. Certificat TLS production

Commande : handshake TLS local (`openssl s_client` + `x509 -noout -dates`).
Résultat : certificat `CN=www.lescaramagnols.com`, émetteur Let's Encrypt (YE1),
valide du 2026-07-04 au **2026-10-02**. ~75 jours de marge au 2026-07-19 ; le
renouvellement récent (04/07) indique que le renouvellement automatique fonctionne.
Le bon fonctionnement du challenge ACME lui-même n'est observable que côté OVH.
