site www.lescaramagnols.com : npm vite composer php js
npm :      gestionnaire de paquets (ou gestionnaire de modules) par défaut pour pour l'écosystème JavaScript et Node.js.
vite :     accélérateur pour développement web front-end et optimiseur pour le code de production
Composer : gestionnaire de dépendances pour PHP, il s'assure que toutes les bibliothèques et tous les outils dont votre application a besoin sont là,
           dans les bonnes versions, et qu'ils fonctionnent harmonieusement ensemble.
langage :  php js
gestion lang via api et js i18n.js
