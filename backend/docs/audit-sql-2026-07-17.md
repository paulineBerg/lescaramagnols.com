### ⚠️ 2. Risques Acceptables (2/134)

#### A. `PrivateBackupService::tableColumns()` et `uniqueIndexes()`
- **Fichier** : `backend/src/PrivatePortal/Operations/PrivateBackupService.php`
- **Lignes** : 869, 891
- **Code** :
  ```php
  $statement = $this->database->pdo()->query(sprintf('DESCRIBE `%s`', $this->database->table($table)));
  $statement = $this->database->pdo()->query(sprintf('SHOW INDEX FROM `%s` WHERE `Non_unique` = 0', $this->database->table($table)));
  ```
- **Source de `$table`** : Payload de backup (fichier JSON charge)
- **Risque** : Un fichier de backup malveillant pourrait contenir un nom de table injecte
- **Mitigations actuelles** :
  - Code d'administration (non accessible publiquement)
  - Fichiers de backup controles par les administrateurs
  - `$this->database->table()` ajoute un prefixe
- **Recommandation** : Ajouter une validation regex dans `validateBackupPayload()` :
  ```php
  if (!preg_match('/^[a-zA-Z0-9_]+$/', $table)) {
      return ['valid' => false, 'error' => 'invalid_table_name'];
  }
  ```
- **Statut** : ❌ **Non corrige** (verifie 2026-07-19)
- **Impact potentiel** : Execution de requetes DESCRIBE/SHOW INDEX sur des tables arbitraires
- **Verdict** : ⚠️ RISQUE THEORIQUE (faible probabilite, impact eleve si exploite)
